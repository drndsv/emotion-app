## О проекте

Данный проект является курсовой работой в рамках курса **«Т-Академия Frontend»**.

**Emotion Diary** — веб-приложение для ведения дневника эмоционального состояния пользователя с использованием искусственного интеллекта для анализа текста записей.

## Задача проекта

Многие люди сталкиваются с трудностями при отслеживании собственного эмоционального состояния, уровня стресса и общего психологического самочувствия.

Цель проекта — предоставить удобный инструмент для:

* ведения эмоционального дневника;
* анализа эмоционального состояния пользователя;
* визуализации статистики и эмоциональных изменений;
* формирования рекомендаций на основе текста записей.

Приложение помогает пользователю лучше понимать свое эмоциональное состояние и замечать изменения настроения со временем.

---

## Целевая аудитория

Приложение ориентировано на:

* людей, которые хотят отслеживать свое эмоциональное состояние;
* пользователей, интересующихся self-care и эмоциональным здоровьем;
* студентов и работающих людей с высоким уровнем стресса;
* пользователей, которым важно анализировать собственные привычки и настроение.

## Возможности приложения

### Авторизация и регистрация

* регистрация и вход через Firebase Authentication;
* защита приватных маршрутов;
* управление профилем пользователя.

### Эмоциональный дневник

* создание записей;
* редактирование записей;
* удаление записей;
* просмотр истории записей;

* анализ текста записи с помощью ИИ;
* определение эмоционального состояния;
* рекомендации на основе содержания записи;
* возможность изменить итоговую эмоцию вручную.

### Дашборд и аналитика

* график распределения эмоций;
* тепловая карта эмоционального состояния;
* отображение последних записей;
* статистика по эмоциональным состояниям.

### Мониторинг и логирование

* сбор событий приложения;
* логирование ошибок;
* продуктовая аналитика;
* отдельная страница мониторинга для администратора;
* хранение логов в Firebase Firestore.

### Адаптивность

Приложение поддерживает мобильную версию и корректно отображается на различных устройствах.

## Маршруты приложения

Основные маршруты:

* `/dashboard` — дашборд пользователя;
* `/journal` — список записей дневника;
* `/journal/:id` — страница отдельной записи (динамический маршрут);
* `/journal/new` — создание записи;
* `/profile` — профиль пользователя;
* `/monitoring` — страница мониторинга (доступна администратору).

---

## Мониторинг и логирование

В приложении реализована система мониторинга и логирования:

* логирование действий пользователя;
* логирование ошибок;
* продуктовая статистика;
* отображение статистики на отдельной странице мониторинга.

Все данные мониторинга хранятся в коллекции `appLogs` в Firebase Firestore.

## Инструкция по запуску проекта

### 1. Клонирование репозитория

```bash
git clone <repository-url>
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Запуск проекта

```bash
nx serve emotion-diary
```

### 4. Запуск линтера

```bash
nx lint emotion-diary
```

### 5. Запуск тестов

```bash
nx test emotion-diary --coverage
```

### 6. Production сборка

```bash
nx build emotion-diary
```

Анализ эмоционального состояния и рекомендации, формируемые ИИ, не являются медицинской консультацией.
